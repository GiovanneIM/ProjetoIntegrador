## 🧾 Descrição do Projeto

**Tema do Projeto:** Sistema de Locação de Veículos

Criar um sistema para gerenciar locações de veículos, incluindo informações sobre carros, clientes e reservas

O site conta com:

- Uma **API** construída com a biblioteca **Express** do **Node.js**  
- Uma **Interface** composta por arquivos **HTML**

## 💡 Ideia Realizada

<p align="center">
  <img src="./logo/logo-semtexto.png" alt="Logo DriveOn" width="120"/>
</p>

Decidimos desenvolver o sistema para uma empresa fictícia de locação de veículos chamada **DriveOn**.

O sistema foi desenvolvido para a navegação do usuário, permitindo que ele crie ou entre em uma conta, veja a frota de veículos e faça a reserva deles.ctiva empresa  

> 🧠 **Resumo:**  
> O sistema exibe ao usuário os veículos dísponiveis para aluguel, crie uma conta e alugue um automóvel.

## 🚀 Como Executar o Projeto

```bash
  # Clone o repositório
  git clone https://github.com/GiovanneIM/ProjetoIntegrador.git

  # Instale as dependências
  npm install

  # Entre na pasta do projeto
  cd Driveon
  
  # Entre na pasta da API
  cd API
  
  # Inicie o servidor Backend
  node server.js
```
Acesse o projeto em: http://localhost:3000
